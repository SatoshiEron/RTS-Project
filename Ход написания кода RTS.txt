Проблема: старый автоген давал квадратные границы (по клеткам сетки). Попытка обрезки через polygon-clipping — сломала топологию (разрывы между соседями).

Решение (Claude):

smoothClusters — сглаживание кластеров на уровне сетки (majority vote). Защита мелких провинций (minProtectedSize = 3).

buildVertexUsageMap — карта использования вершин: usage >= 2 — межпровинциальные, usage == 1 — берег.

chaikinOpen / chaikinClosed — сглаживание берега с фиксацией концов (разрыв геометрически невозможен).

smoothCoastlineOnly — сглаживает только берег, межпровинциальные вершины не двигает.

Результат: границы плавнее, разрывов меньше, но:

Берег не совпадает точно с исходным PNG.

Точки-сироты — бывшие вершины берега, не используются.

Откат: CDN polygon-clipping удалён, simplifyPolygon не вызывается.

**Что реализовано**
• Гибридная экономика: доход города делится на `treasuryShare` (в казну) и `1 - treasuryShare` (в `city.resources`)
• Политика финансирования: `self` (город платит сам) / `center` (казна платит)
• Единые формулы: `20 + level*5` (найм), `30 + level*15` (улучшение) — для игрока и ИИ
• Лимит уровня: 5 — единый для всех
• Фикс бага ID юнитов: `CityPanel` больше не создаёт юнитов в обход `game.spawnUnit`
• Панель фракции: казна, распределение дохода, ползунок 0–100%, переключатель политики, заглушки «Древо технологий / Решения / Политика»
• Уведомление о нехватке: с ценой, доступным, кнопкой «переключить на казну»

**Что НЕ реализовано / ограничения**
• Сохранения — в игре нет системы сохранений, `factionEconomy` не сохраняется между сессиями. По ТЗ п.9 — «не добавлять, пока не проверена архитектура». Проверено: сохранений нет
• Мобильный экран — не тестировали
• `EconomySystem.js` — остался как мёртвый модуль (помечен комментарием в `GameState`). Удалять не стали — вдруг пригодится
• `getNetIncome` — не учитывает `treasuryShare`, возвращает полный доход города. В `FactionPanel` используется ручной расчёт. Метод не тронут, чтобы не ломать `index.html`
• Тесты п.10 ТЗ — прогнаны частично (вручную в консоли). Полный чек-лист не пройден
• Военный ИИ — не трогали. Работоспособность после изменений не верифицирована отдельно

**Где архитектура не позволила**
• `EconomySystem.js` — второй, мёртвый механизм экономики. Удалять — риск сломать что-то, что не видел. Оставил с комментарием «не использовать»
• `AIConfig.UNIT_COST` / `UPGRADE_COST` — удалены (единые формулы), но формально это «удаление существующего поля». Обосновано: держать два источника цен — прямой путь к расхождению
• `getNetIncome` — не переписан под `treasuryShare`, потому что вызывается из `index.html` и отображается в `goldChange`. Переписывание сломало бы отображение «чистый доход» в правом верхнем углу. Решение: в `FactionPanel` считается отдельно

**Сценарии, требующие ручной проверки**
• 0% отчислений → всё в городе
• 100% → всё в казну
• 40% от 100 → 40 / 60
• Нет двойного начисления
• `self` → списание только с `city.resources`
• `center` → списание только с казны
• Нехватка → без изменений
• ИИ и игрок — одинаково
• Upkeep / провинции работают
• Ползунок / политика не ломают цикл
• Военный ИИ работает
• Консоль чистая
